# 엘리쌤 브랜드 문구 후보

## 핵심 기억

엘리쌤 영어 브랜드의 문구는 국제학교 학생 이해, 쉬운 설명, 시간 효율성, Academic English 개념 정리, 과장 없는 프리미엄 이미지를 반복해서 보여줘야 한다.

## 세부 내용

| 용도 | 문구 |
| --- | --- |
| 메인 카피 | 국제학교 학생이 영어로 배우는 개념을 더 쉽고 빠르게 이해하도록 돕는 강의 |
| 문제 제기 | 영어 수업을 듣고 있어도, 개념이 머릿속에 정리되지 않는다면 |
| 학습 방식 | 혼자 들어도 이해되고, 혼자 복습할 기준이 남는 Academic English |
| 시간 효율 | GPA, AP, SAT, TOEFL까지 바쁜 국제학교 생활 속 시간을 전략적으로 쓰는 영어 강의 |
| 학부모 메시지 | 과장 없이, 학생에게 실제로 필요한 도움을 주는 no-nonsense English 강의 |
| 이미지 문구 | 국제학교 학생을 잘 이해하는 강의 |
| 보충 필요성 | 따로 보충이 필요 없도록 개념과 공부 방향을 정리해주는 강의 |

반복 키워드:

- 국제학교
- 쉬운 설명
- Academic English
- GPA
- AP
- SAT
- TOEFL
- 시간 효율성
- 이해 중심 학습
- 학생 맞춤형 커리큘럼
- no-nonsense marketing
- 프리미엄하지만 과장되지 않은
- 실제로 이해되는 강의
