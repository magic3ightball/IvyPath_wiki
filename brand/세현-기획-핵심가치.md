# 세현 기획 핵심가치

## 핵심 기억

세현의 기획 핵심가치는 명확한 개념 이해, 국제학교식 적용력, 지루하지 않은 몰입형 학습 경험이다.

## 세부 내용

| 핵심가치 | 의미 | 구현 방식 |
| --- | --- | --- |
| 명확한 개념 이해 | 영어로 배운 어려운 개념을 머릿속에 정리한다 | 영어 원문 개념을 쉽게 풀고 한국어 정리와 연결한다 |
| 국제학교식 적용력 | 학교 수업·시험·과제에 스스로 적용하게 한다 | 문제 접근법, 에세이형 과제, 서술형 답안 구조를 함께 설명한다 |
| 지루하지 않은 몰입형 학습 경험 | 온라인 강의의 단조로움과 집중력 저하를 해결한다 | 라이트보드를 통해 개념의 흐름과 연결을 시각적으로 보여준다 |

반드시 가져야 할 가치:

- 명확성
- 구조화
- 쉬운 설명
- 국제 커리큘럼 적합성
- 영어 원문 이해
- 개념 중심
- 시험 적용력
- 과제 적용력
- 신뢰성
- 반복 학습 가능성
- 라이트보드 기반 재미와 몰입감
