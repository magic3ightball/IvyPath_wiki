# 플랫폼 브랜드 방향

## 핵심 기억

플랫폼 방향은 라이트보드 기반 국제학교 학생 맞춤 인강이다. 국제학교 학생이 영어로 배우는 개념을 혼자서도 이해하고, 학교 수업·시험·과제에 적용할 수 있도록 돕는 재미있고 구조화된 온라인 강의가 되어야 한다.

## 세부 내용

| 항목 | 기억 |
| --- | --- |
| 플랫폼 방향 | 라이트보드 기반 국제학교 학생 맞춤 인강 |
| 핵심 문제 | 영어로 배우는 개념이 명확히 정리되지 않고 시험·과제에 적용되지 않는 문제 |
| 해결 방식 | 원문 개념 이해, 구조화된 설명, 시각적 설명, 반복 학습, 적용력 |
| 학습 경험 | 지루하지 않은 몰입형 강의, 개념이 눈앞에서 정리되는 경험 |
| 브랜드 기준 | 쉽지만 얕지 않고, 체계적이지만 부담스럽지 않으며, 재미있지만 가볍지 않은 강의 |
